# Documentation

Thư mục này chứa tất cả tài liệu của dự án.

## 📚 Danh Sách Tài Liệu

### Cơ Bản
- **README.md** - Tài liệu tổng quan về dự án, hướng dẫn cài đặt và sử dụng
- **SETUP.md** - Hướng dẫn setup và cấu hình môi trường phát triển

### Kiến Trúc & Thiết Kế
- **ARCHITECTURE.md** - Kiến trúc hệ thống, cấu trúc dự án và design patterns

### API Documentation
- **API_DOCUMENTATION.md** - Hướng dẫn sử dụng API và các endpoints
- **swagger.yaml** - OpenAPI/Swagger specification file

### Testing
- **TESTING.md** - Hướng dẫn chạy unit tests
- **UNIT_TEST_STANDARDS.md** - Chuẩn và best practices cho unit testing
- **README_TEST_REPORTS.md** - Hướng dẫn sử dụng test reports
- **README_WEB_REPORTS.md** - Hướng dẫn truy cập test reports qua web

### Debugging & Development
- **BUGS_INTRODUCED.md** - Danh sách bugs được thêm vào để test unit tests

## 🔗 Xem Tài Liệu Trực Tuyến

- **Home**: `http://localhost:8000`
- **API Docs**: `http://localhost:8000/api-docs.html`
- **Test Reports**: `http://localhost:8000/test-reports`
- **Swagger YAML**: `http://localhost:8000/swagger.yaml`
